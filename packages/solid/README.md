# @roboto_/wotlk-viewer-solid

SolidJS 2.0 components for [`@roboto_/wotlk-viewer-core`](https://www.npmjs.com/package/@roboto_/wotlk-viewer-core):
`<WowViewer>`, `<Model>`, `<Character>`, `<Creature>`, `<Item>`, `<Backdrop>` and `useViewer()`.

```bash
npm install @roboto_/wotlk-viewer-solid @roboto_/wotlk-viewer-core three solid-js @solidjs/web
```

See the [repository README](https://github.com/r-o-b-o-t-o/wotlk-viewer#solidjs) for usage.
