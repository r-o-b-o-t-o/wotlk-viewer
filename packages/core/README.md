# @roboto_/wotlk-viewer-core

WebGL renderer for World of Warcraft: Wrath of the Lich King (3.3.5a) models on [three.js](https://threejs.org). It
parses M2, SKIN, ANIM, BLP and DBC files straight from an extracted client and assembles fully equipped player
characters, creatures and items. UI-framework agnostic.

```bash
npm install @roboto_/wotlk-viewer-core three
```

It needs an extracted 3.3.5a client served over HTTP, for example by
[`@roboto_/wotlk-viewer-server`](https://www.npmjs.com/package/@roboto_/wotlk-viewer-server).
See the [repository README](https://github.com/r-o-b-o-t-o/wotlk-viewer#readme) for usage.
