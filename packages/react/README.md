# @roboto_/wotlk-viewer-react

React components for [`@roboto_/wotlk-viewer-core`](https://www.npmjs.com/package/@roboto_/wotlk-viewer-core):
`<WowViewer>`, `<Model>`, `<Character>`, `<Creature>`, `<Item>`, `<Backdrop>` and `useViewer()`.

```bash
npm install @roboto_/wotlk-viewer-react @roboto_/wotlk-viewer-core three react
```

See the [repository README](https://github.com/r-o-b-o-t-o/wotlk-viewer#react) for usage.
